# Axon UI

React component library with prebuilt forms, AI chat interfaces, charts and data tables.

| Package        | Purpose                                         |
| -------------- | ----------------------------------------------- |
| `@axon/theme`  | Design tokens, `ThemeProvider`, light/dark mode |
| `@axon/core`   | Base controls                                   |
| `@axon/forms`  | Form engine and prebuilt forms                  |
| `@axon/chat`   | AI chat window and related components           |
| `@axon/charts` | SVG charts                                      |
| `@axon/table`  | Data grid                                       |

More documentation arrives with each package.
