# Changelog

Each package keeps its own changelog (`packages/<name>/CHANGELOG.md`), written by [Changesets](https://github.com/changesets/changesets) when a release is made. This file records the repository as a whole.

## Unreleased

The first release, 0.1.0 of every package, is pending in `.changeset/first-release.md`.

- `@axon/theme`: design tokens, `ThemeProvider`, light, dark and system modes, `createTheme`.
- `@axon/core`: accessible base components.
- `@axon/forms`: form engine and prebuilt forms.
- `@axon/chat`: AI chat components.
- `@axon/charts`: accessible SVG charts.
- `@axon/table`: `Table` and `DataGrid`.
